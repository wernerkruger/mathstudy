**11.**
a) For even $n$, $(-x)^n = x^n$, so $(x,y)$ and $(-x,y)$ are both on the graph: $y = x^2$, $y = x^4$ and $y = x^{-2}$ are symmetric in the $y$-axis.
For odd $n$, $(-x)^n = -x^n$, so with $(x, y)$ also $(-x, -y)$ is on the graph: $y = x^3$ and $y = x^{-1}$ are point-symmetric in the origin.
$y = \sqrt{x}$ has neither symmetry (it is not even defined for $x < 0$).
b) $y = x^{-1}$ and $y = x^{-2}$: vertical asymptote $x = 0$ and horizontal asymptote $y = 0$. The others have no asymptotes.
c) At $x = 2$: $x^2 = 4$, $x^3 = 8$, $x^4 = 16$, $x^{-1} = \tfrac12$, $x^{-2} = \tfrac14$, $\sqrt2 \approx 1.41$. Only $y = x^{-2}$ passes through $(2, \tfrac14)$.
At $x = -1$: $(-1)^3 = -1$ and $(-1)^{-1} = -1$; $(-1)^2 = (-1)^4 = (-1)^{-2} = 1$; $\sqrt{-1}$ does not exist. So $y = x^3$ and $y = x^{-1}$ pass through $(-1,-1)$.
d) $x^4 = x^2 \cdot x^2$. For $0 < x < 1$ we have $0 < x^2 < 1$, and multiplying the positive number $x^2$ by a number less than 1 makes it smaller: $x^2 \cdot x^2 < x^2$.

**12.**
a) The job takes $12 \cdot 10 = 120$ worker-days. 15 workers: $120 / 15 = 8$ days. 8 workers: $120/8 = 15$ days.
b) $x \cdot y$: $1 \cdot 24 = 2 \cdot 12 = 3 \cdot 8 = 4 \cdot 6 = 6 \cdot 4 = 24$. The product is constant, so $x$ and $y$ are inversely proportional: $y = \dfrac{24}{x}$.
c) Vertical asymptote $x = 0$, horizontal asymptote $y = 0$.

## Challenge

**22.**
a) $2^{300} = (2^3)^{100} = 8^{100}$ and $3^{200} = (3^2)^{100} = 9^{100}$. Since $8 < 9$, $8^{100} < 9^{100}$: **$3^{200}$ is bigger**.
b) Raise both (positive) numbers to the 30th power; this keeps the order, because for positive numbers $a < b$ implies $a^{30} < b^{30}$.
$\left(10^{1/10}\right)^{30} = 10^3 = 1000$ and $\left(2^{1/3}\right)^{30} = 2^{10} = 1024$. So **$\sqrt[3]{2}$ is bigger**.
c) *Lower bound for $2^{100}$.* $2^{100} = (2^{10})^{10} = 1024^{10} = (10^3 \cdot 1.024)^{10} = 10^{30} \cdot 1.024^{10}$.
Write $1.024^{10} = (1 + 0.024)(1 + 0.024)\cdots(1 + 0.024)$ (ten brackets). Expanding, choosing 1 from every bracket gives 1; choosing 0.024 from exactly one bracket gives ten terms $0.024$; all other terms are positive. So $1.024^{10} > 1 + 10 \cdot 0.024 = 1.24$, and $2^{100} > 1.24 \cdot 10^{30}$.
*Upper bound for $3^{63}$.* $3^{63} = (3^{21})^3$ and $3^{21} = 10\,460\,353\,203 < 1.05 \cdot 10^{10}$. So $3^{63} < 1.05^3 \cdot 10^{30} = 1.157625 \cdot 10^{30}$.
Since $1.157625 < 1.24$: $3^{63} < 1.16 \cdot 10^{30} < 1.24 \cdot 10^{30} < 2^{100}$. **$2^{100}$ is bigger.**
(Check: $2^{100} \approx 1.268 \cdot 10^{30}$ and $3^{63} \approx 1.145 \cdot 10^{30}$. The two are close because $\tfrac{100}{63} \approx 1.5873$ is only slightly larger than the number $x$ with $2^x = 3$, which is about 1.585.)

**23.**
a) Last digits of $7^1, 7^2, 7^3, 7^4, 7^5, \ldots$: $7, 9, 3, 1, 7, \ldots$ The last digit of a product only depends on the last digits of the factors, so the pattern repeats with period 4. $2027 = 4 \cdot 506 + 3$, so $7^{2027}$ ends like $7^3 = 343$: last digit **3**.
b) Powers of 2 end in $2, 4, 8, 6, \ldots$ (period 4), so $2^{2027}$ ends like $2^3$: 8. Powers of 3 end in $3, 9, 7, 1, \ldots$, so $3^{2027}$ ends like $3^3 = 27$: 7. The sum ends like $8 + 7 = 15$: last digit **5**.

**24.**
a) *Lemma: if $p^2$ is a multiple of 3, then $p$ is.* If $p$ is not a multiple of 3, then $p = 3k + 1$ or $p = 3k + 2$. Then $p^2 = 9k^2 + 6k + 1 = 3(3k^2 + 2k) + 1$ or $p^2 = 9k^2 + 12k + 4 = 3(3k^2 + 4k + 1) + 1$; in both cases $p^2$ leaves remainder 1 on division by 3, so it is not a multiple of 3.
*Proof.* Suppose $\sqrt3 = \tfrac pq$ in lowest terms. Then $p^2 = 3q^2$, so $p^2$ is a multiple of 3, so $p$ is (lemma): $p = 3k$. Then $9k^2 = 3q^2$, so $q^2 = 3k^2$, so $q$ is a multiple of 3 too. Then $p$ and $q$ have common factor 3, contradicting lowest terms. So $\sqrt3$ is irrational. $\blacksquare$
b) For $\sqrt4$ we would get $p^2 = 4q^2$, and the argument would need "if $4$ divides $p^2$, then $4$ divides $p$". That is false: $p = 2$ (or $p = 6$) has $p^2$ divisible by 4 but $p$ is not. So the step from $p^2$ to $p$ breaks. Indeed $\sqrt4 = \tfrac21$, with $p = 2$, $q = 1$. (The lemma works for 2 and 3 because they are prime; for a prime $r$, if $r$ divides $p^2$ then $r$ divides $p$.)
c) *First, $\sqrt6$ is irrational.* Suppose $\sqrt6 = \tfrac pq$ in lowest terms. Then $p^2 = 6q^2$ is even, so $p$ is even: $p = 2k$. Then $4k^2 = 6q^2$, so $2k^2 = 3q^2$. So $3q^2$ is even; since 3 is odd, $q^2$ must be even (odd times odd is odd), so $q$ is even. Both even: contradiction.
*Now $\sqrt2 + \sqrt3$.* Suppose $\sqrt2 + \sqrt3 = r$ with $r$ rational. Squaring: $2 + 2\sqrt6 + 3 = r^2$, so $\sqrt6 = \dfrac{r^2 - 5}{2}$. The right side is rational (sums, products and quotients of rationals are rational), but $\sqrt6$ is irrational. Contradiction, so $\sqrt2 + \sqrt3$ is irrational. $\blacksquare$

**25.**
a) $4^x + 4^x + 4^x + 4^x = 4 \cdot 4^x = 4^{x+1} = 2^{2(x+1)} = 2^{2x+2}$. So $2x + 2 = 20$, **$x = 9$**.
b) $2^x \cdot (2^2)^{x+1} = (2^5)^{x-2}$ gives $2^{x + 2x + 2} = 2^{5x - 10}$, so $3x + 2 = 5x - 10$, **$x = 6$**. Check: $2^6 \cdot 4^7 = 2^6 \cdot 2^{14} = 2^{20}$ and $32^4 = 2^{20}$.
c) $(3^2)^x = 3 \cdot (3^3)^{x-1}$ gives $3^{2x} = 3^{1 + 3x - 3} = 3^{3x - 2}$, so $2x = 3x - 2$, **$x = 2$**. Check: $9^2 = 81$ and $3 \cdot 27 = 81$.
(We used: if $2^m = 2^n$ then $m = n$. This holds because $2^x$ is increasing, so different exponents give different values.)

**26.** Idea: $(\sqrt m + \sqrt n)^2 = m + n + 2\sqrt{mn}$. Look for $m + n$ and $mn$.
a) $3 + 2\sqrt2$: need $m + n = 3$, $mn = 2$: $m = 2$, $n = 1$. So $\sqrt{3 + 2\sqrt2} = \sqrt2 + 1$. Check: $(1 + \sqrt2)^2 = 1 + 2\sqrt2 + 2 = 3 + 2\sqrt2$.
b) $7 - 4\sqrt3 = 7 - 2\sqrt{12}$: need $m + n = 7$, $mn = 12$: $m = 4$, $n = 3$. So $\sqrt{7 - 4\sqrt3} = \sqrt4 - \sqrt3 = 2 - \sqrt3$. We must take $2 - \sqrt3$ and not $\sqrt3 - 2$, because a square root is non-negative and $2 - \sqrt3 > 0$. Check: $(2 - \sqrt3)^2 = 4 - 4\sqrt3 + 3 = 7 - 4\sqrt3$.
c) $11 + 6\sqrt2 = 11 + 2\sqrt{18}$: $m + n = 11$, $mn = 18$: $m = 9$, $n = 2$. So $\sqrt{11 + 6\sqrt2} = 3 + \sqrt2$. Check: $(3 + \sqrt2)^2 = 9 + 6\sqrt2 + 2 = 11 + 6\sqrt2$.
d) $5 + 2\sqrt6$: $m + n = 5$, $mn = 6$: $m = 3$, $n = 2$. So $\sqrt{5 + 2\sqrt6} = \sqrt3 + \sqrt2$. Check: $(\sqrt3 + \sqrt2)^2 = 3 + 2\sqrt6 + 2$.

(With logarithms in C2 you will see that the exact doubling time is $\dfrac{\ln 2}{\ln(1 + p/100)}$, and that for small $p$ this is close to $\dfrac{69.3}{p}$.)
