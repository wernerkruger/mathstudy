**7.** (a) $2x + 6 = 2x + 5$; subtracting $2x$ gives $6 = 5$, which is false for every $x$. **No solution.** (The lines $y = 2x + 6$ and $y = 2x + 5$ are parallel.)

**8.** (a) $3x < 15$, so $x < 5$.

(d) $2x - 6 - 5x \le x + 10$, so $-3x - 6 \le x + 10$, so $-4x \le 16$. Divide by $-4$ and flip: $x \ge -4$. (Or: add $3x$ and subtract 10 to get $-16 \le 4x$, so $-4 \le x$, without any flipping.)

**11.** Table of values:

**12.** Write each equation as $y = \ldots$: $2x - 3y = 6$ becomes $y = \tfrac23 x - 2$.

(a) $4x - 6y = 12$ becomes $y = \tfrac23 x - 2$: the same line. **Infinitely many solutions**: every pair $(x, \tfrac23 x - 2)$, for example $(0, -2)$, $(3, 0)$, $(6, 2)$.

(b) $4x - 6y = 10$ becomes $y = \tfrac23 x - \tfrac53$: same slope, different start value, so parallel. **No solution.** Algebraically: twice the first equation is $4x - 6y = 12$; subtracting the second gives $0 = 2$.

(c) $3x + 2y = 9$ becomes $y = -\tfrac32 x + \tfrac92$: different slope, so **exactly one solution**. (The slopes $\tfrac23$ and $-\tfrac32$ even multiply to $-1$: the lines are perpendicular.) Elimination: twice the first gives $4x - 6y = 12$, three times the second gives $9x + 6y = 27$; adding gives $13x = 39$, so $x = 3$, then $6 - 3y = 6$, so $y = 0$. Solution: $(3, 0)$.

**13.** The perpendicular slope is $-\dfrac{1}{2/3} = -\dfrac32$ (check: $\tfrac23 \cdot -\tfrac32 = -1$). Through $(4, 1)$: $1 = -\tfrac32 \cdot 4 + b = -6 + b$, so $b = 7$.

Answer: $y = -\tfrac32 x + 7$.

## Challenge

**23.** Double the first equation and subtract the second:
$$
(4x + 2py) - (4x + 6y) = 10 - q \quad\Longrightarrow\quad (2p - 6)\,y = 10 - q.
$$
By §6.5 this equation together with the first equation forms a system equivalent to the original one.

- If $2p - 6 \neq 0$, that is $p \neq 3$, then $y = \dfrac{10 - q}{2p - 6}$ and there is exactly one solution.
- If $p = 3$, the equation reads $0 = 10 - q$.

(a) **No solution** when $p = 3$ and $q \neq 10$. (Then both lines have slope $-\tfrac23$ but the second is not twice the first.)

(b) **Infinitely many** when $p = 3$ and $q = 10$: the second equation is then exactly twice the first, so it is the same line $2x + 3y = 5$.

(c) **Exactly one** when $p \neq 3$ (any $q$). Then
$$
y = \frac{10 - q}{2p - 6}, \qquad x = \frac{5 - py}{2} = \frac{pq - 30}{4p - 12}.
$$
(Working for $x$: $5 - py = \dfrac{5(2p - 6) - p(10 - q)}{2p - 6} = \dfrac{pq - 30}{2p - 6}$, then divide by 2.)

**24.** $OP^2 = 1^2 + a_1^2$, $OQ^2 = 1^2 + a_2^2$ and $PQ^2 = 0^2 + (a_1 - a_2)^2$.

If $a_1 = a_2$ the two lines coincide, are not perpendicular, and $a_1 a_2 = a_1^2 > 0 \neq -1$, so the statement holds. Assume now $a_1 \neq a_2$, so $O$, $P$, $Q$ form a triangle ($P$ and $Q$ are different points on the vertical line $x = 1$, and $O$ is not on that line).

By Pythagoras' theorem and its converse, the angle at $O$ is right exactly when $OP^2 + OQ^2 = PQ^2$:
$$
\begin{aligned}
(1 + a_1^2) + (1 + a_2^2) &= (a_1 - a_2)^2 \\
2 + a_1^2 + a_2^2 &= a_1^2 - 2a_1 a_2 + a_2^2 \\
2 &= -2a_1 a_2 \\
a_1 a_2 &= -1.
\end{aligned}
$$
Each step can be reversed, so: angle $POQ$ is $90°$ $\iff$ $a_1 a_2 = -1$. Since angle $POQ$ is the angle between $\ell_1$ and $\ell_2$, this proves $\ell_1 \perp \ell_2 \iff a_1 a_2 = -1$. Lines with the same slopes that do not pass through the origin are parallel to these, so the rule holds for all non-vertical, non-horizontal lines.

**25.** (a) $y \ge 1$ and $x \ge 1$ means $5y \le 47 - 3 = 44$, so $y \le 8$. For each $y$ from 1 to 8, $47 - 5y$ must be a positive multiple of 3:

| $y$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| $47 - 5y$ | 42 | 37 | 32 | 27 | 22 | 17 | 12 | 7 |
| multiple of 3? | yes | no | no | yes | no | no | yes | no |

So the solutions are $(x, y) = (14, 1)$, $(9, 4)$ and $(4, 7)$. We checked every possible $y$, so there are no others. Notice the pattern: going from one solution to the next, $x$ drops by 5 and $y$ rises by 3, which keeps $3x + 5y$ the same ($-15 + 15 = 0$).

(b) $8 = 3 + 5$, $9 = 3 + 3 + 3$, $10 = 5 + 5$. Now every $n \ge 11$ is $3$ more than a number $n - 3 \ge 8$. Starting from 8, 9 and 10 and adding packs of 3 again and again, we reach 11, 12, 13, then 14, 15, 16, and so on: every whole number $n \ge 8$. (This is a proof by induction.)

Impossible amounts below 8: 3, 5 and 6 are possible ($3$, $5$, $3 + 3$). For 1, 2 and 4 the only multiples of 5 that fit are 0, and 1, 2, 4 are not multiples of 3. For 7: using 0 packs of 5 needs $7 = 3x$, impossible; using one pack of 5 leaves 2, not a multiple of 3. So the impossible amounts are exactly **1, 2, 4 and 7**.

**26.** Add the first and third equation: $2x + 3y = 8$. Add the second and third: $3x + y = 5$. Now $z$ is gone. From $3x + y = 5$: $y = 5 - 3x$. Substitute: $2x + 3(5 - 3x) = 8$, so $-7x = -7$, so $x = 1$, $y = 2$. From the first equation, $z = 6 - 1 - 2 = 3$.

**27.** Write $E_1$ as $L_1 = R_1$ and $E_2$ as $L_2 = R_2$.

(a) If $(x, y)$ satisfies $E_1$ and $E_2$, then adding $k$ times the true statement $L_1 = R_1$ to the true statement $L_2 = R_2$ gives the true statement $L_2 + kL_1 = R_2 + kR_1$. Conversely, if $(x, y)$ satisfies $E_1$ and $L_2 + kL_1 = R_2 + kR_1$, then subtracting $k$ times $L_1 = R_1$ gives $L_2 = R_2$. So the two systems have exactly the same solutions.

(b) If $L_1 = R_1$ then $mL_1 = mR_1$. Conversely, if $mL_1 = mR_1$ and $m \neq 0$, divide by $m$ to get $L_1 = R_1$. The second equation is unchanged. So the systems have the same solutions.

(c) Take $E_1$: $x + y = 2$ and $E_2$: $x - y = 0$. This system has exactly one solution, $(1, 1)$. Multiplying $E_1$ by $m = 0$ gives $0 = 0$, and the system $\{0 = 0,\ x - y = 0\}$ is solved by every pair with $x = y$, for example $(5, 5)$. Solutions were gained, because the step "divide by $m$" cannot be done when $m = 0$.

**28.** (a) Rewrite: $y = p(x + 2) - 3$, so $y + 3 = p(x + 2)$. For $x = -2$ the right-hand side is 0 whatever $p$ is, so $y = -3$. So every line $\ell_p$ passes through $(-2, -3)$. (It is the only common point, because for example $\ell_0$: $y = -3$ and $\ell_1$: $y = x - 1$ meet only there.)

(b) If $p = 0$, the line is $y = -3$, which does not meet the $x$-axis. If $p \neq 0$, the line meets the $x$-axis where $0 = p(x + 2) - 3$, so $x = \dfrac3p - 2$. We need $0 \le \dfrac3p - 2 \le 4$, that is $2 \le \dfrac3p \le 6$. Since $\dfrac3p \ge 2 > 0$, $p$ must be positive, so we may multiply by $p$ without flipping: $2p \le 3 \le 6p$. So $p \le \tfrac32$ and $p \ge \tfrac12$.

Answer: $\tfrac12 \le p \le \tfrac32$.

Geometric check: all lines pass through $(-2, -3)$. The line to $(0, 0)$ has slope $\frac{3}{2}$ and the line to $(4, 0)$ has slope $\frac{3}{6} = \frac12$. Lines with slopes in between sweep across the segment.

**29.** Let the tens digit be $t$ and the units digit $e$, so the number is $10t + e$ and the swapped number is $10e + t$.
$$
\begin{cases}
t + e = 11 \\
(10e + t) - (10t + e) = 27
\end{cases}
$$
The second equation simplifies to $9e - 9t = 27$, so $e - t = 3$. Adding this to $t + e = 11$ gives $2e = 14$, so $e = 7$ and $t = 4$. The number is **47** (check: $4 + 7 = 11$ and $74 - 47 = 27$). The system has exactly one solution (the lines $t + e = 11$ and $e - t = 3$ have different slopes), so 47 is the only such number.

**30.** (a) $2x + 1 = -x + 7$ gives $x = 2$, $y = 5$. The third line must pass through $(2, 5)$: $5 = \tfrac12 \cdot 2 + k = 1 + k$, so $k = 4$.

(b) The vertices of the triangle are: the intersection point $(2, 5)$; where $y = 2x + 1$ meets the $x$-axis, $x = -\tfrac12$; where $y = -x + 7$ meets the $x$-axis, $x = 7$.
