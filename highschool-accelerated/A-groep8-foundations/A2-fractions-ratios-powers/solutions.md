## Challenge

### 18.

(a) **Lemma.** If $3 \mid a^2$ then $3 \mid a$.
*Proof.* If $3 \nmid a$, then $a = 3k + 1$ or $a = 3k + 2$. Then $a^2 = 9k^2 + 6k + 1 = 3(3k^2 + 2k) + 1$ or $a^2 = 9k^2 + 12k + 4 = 3(3k^2 + 4k + 1) + 1$. Either way $a^2$ leaves remainder 1, so $3 \nmid a^2$. That is the contrapositive of the lemma. $\square$

**Theorem.** $\sqrt3$ is irrational.
*Proof.* Suppose $\sqrt3 = \dfrac{a}{b}$ in lowest terms. Then $a^2 = 3b^2$, so $3 \mid a^2$, so $3 \mid a$ by the lemma. Write $a = 3c$: then $9c^2 = 3b^2$, so $b^2 = 3c^2$, so $3 \mid b^2$ and $3 \mid b$. Then 3 divides both $a$ and $b$, contradicting lowest terms. So $\sqrt3$ is not a fraction. $\square$

(b) For $\sqrt4$ we would need: "if $4 \mid a^2$ then $4 \mid a$". That's **false**: $4 \mid 2^2$ but $4 \nmid 2$. So the step "$4 \mid a^2 \Rightarrow 4 \mid a$" fails, and the proof breaks there. Good: $\sqrt4 = 2 = \tfrac21$ is rational, so any correct proof *must* fail for it. Checking that a proof fails where the result is false is a useful habit.

### 19.

**Argument 1 (algebra).** Let $x = 0.\overline{9}$. Then $10x = 9.\overline{9}$, and subtracting, $9x = 9$, so $x = 1$.

**Argument 2 (thirds).** $\tfrac13 = 0.\overline{3}$. Multiply by 3: $1 = 0.\overline{9}$.

**Argument 3 (nothing in between).** If $0.\overline{9} < 1$, the number halfway between them would be bigger than $0.\overline{9}$ but less than 1. Any number less than 1 has a decimal $0.d_1d_2d_3\ldots$ with some digit less than 9 (otherwise it *is* $0.\overline{9}$). Then it is smaller than $0.\overline{9}$, which has 9 in every place. So no number lies strictly between $0.\overline{9}$ and $1$, and they must be equal. (Or: the difference $1 - 0.\overline{9}$ is smaller than $0.1$, than $0.01$, than $0.001$, …, than every positive number, so it is 0.)

### 20.

Let $\dfrac{a}{b}$ be in lowest terms, so $\gcd(a, b) = 1$.

**If** $b = 2^i5^j$: let $k$ be the larger of $i$ and $j$. Then $10^k = 2^k5^k$ is a multiple of $b$, say $10^k = b\cdot m$. So $\dfrac{a}{b} = \dfrac{am}{10^k}$, which is a terminating decimal (the whole number $am$ with the point moved $k$ places).

**Only if:** suppose $\dfrac{a}{b}$ terminates, so $\dfrac{a}{b} = \dfrac{N}{10^k}$ for some whole numbers $N$ and $k$. Then $a\cdot 10^k = N\cdot b$, so $b$ divides $a\cdot 10^k$. Let $p$ be any prime factor of $b$. Then $p$ divides $a\cdot 10^k = a\cdot 2^k\cdot 5^k$. By uniqueness of prime factorisation, $p$ appears in the factorisation of $a$ or $p = 2$ or $p = 5$. But $p$ can't divide $a$, since $\gcd(a, b) = 1$. So $p = 2$ or $p = 5$. $\square$

(Why lowest terms matters: $\tfrac{3}{6}$ has a 3 in the denominator but terminates, because the 3 cancels.)

### 21.

(a)

$$
\tfrac17 = 0.\overline{142857},\ \tfrac27 = 0.\overline{285714},\ \tfrac37 = 0.\overline{428571},\ \tfrac47 = 0.\overline{571428},\ \tfrac57 = 0.\overline{714285},\ \tfrac67 = 0.\overline{857142}.
$$

They all use the **same six digits in the same cyclic order**, just starting at a different place. (In the long division of $1 \div 7$, all six non-zero remainders appear; $\tfrac{k}{7}$ simply starts the same cycle at remainder $k$.)

(b) $\tfrac{1}{13} = 0.\overline{076923}$: period **6**. $\tfrac{1}{17} = 0.\overline{0588235294117647}$: period **16**.

(c) In the long division of $1 \div n$, each step has a remainder in $\lbrace 0, 1, \dots, n - 1\rbrace$. If a remainder is 0, the decimal terminates. Otherwise every remainder is one of the $n - 1$ values $1, \dots, n-1$. Each next step depends only on the current remainder. Among the first $n$ remainders, two must be equal (only $n - 1$ possible values), and from the first repeated remainder onwards the digits repeat. So the repeating block is at most $n - 1$ long.

### 23.

$2^{100} = (2^{10})^{10} = 1024^{10} = (1.024\times 10^3)^{10} = 1.024^{10}\times 10^{30}$.

Since $1.024 > 1$, $1.024^{10} > 1$, so $2^{100} > 10^{30}$, which has 31 digits. If also $1.024^{10} < 10$, then $2^{100} < 10^{31}$, the smallest 32-digit number. So $2^{100}$ has **31 digits**.

Proof that $1.024^{10} < 1.3$ (which is far more than we need):

- $1.024^2 = 1.048576 < 1.05$;
- so $1.024^4 < 1.05^2 = 1.1025$;
- so $1.024^8 < 1.1025^2 = 1.21550625 < 1.22$;
- so $1.024^{10} = 1.024^8\cdot 1.024^2 < 1.22\cdot 1.05 = 1.281 < 1.3$.

(Calculator: $1.024^{10} \approx 1.268$, so $2^{100} \approx 1.268\times 10^{30}$.)

### 24.

Growth factors: $\left(1 + \tfrac{p}{100}\right)\left(1 - \tfrac{p}{100}\right) = 0.96$. Write $q = \tfrac{p}{100}$. Then $(1 + q)(1 - q) = 1 - q^2$ (expand the brackets: $1 - q + q - q^2$). So $1 - q^2 = 0.96$, $q^2 = 0.04$, $q = 0.2$ (as $q > 0$). So $p = $ **20**.

### 26.

(a) Mediant: $\dfrac{1 + 2}{2 + 3} = \dfrac35 = 0.6$, and $\tfrac12 = 0.5 < 0.6 < 0.666\ldots = \tfrac23$. ✓

(b) All of $a, b, c, d$ are positive, so we can multiply inequalities by denominators without changing direction. $\dfrac{a}{b} < \dfrac{c}{d}$ means $ad < bc$.

*Left inequality:* $\dfrac{a}{b} < \dfrac{a + c}{b + d}$ means $a(b + d) < b(a + c)$, that is $ab + ad < ab + bc$, that is $ad < bc$. True.

*Right inequality:* $\dfrac{a + c}{b + d} < \dfrac{c}{d}$ means $d(a + c) < c(b + d)$, that is $ad + cd < bc + cd$, that is $ad < bc$. True. $\square$

(Picture: think of $\tfrac{a}{b}$ as a slope. Adding the vectors $(b, a)$ and $(d, c)$ gives a slope between the two.)

(c) Given two fractions $x < y$, the mediant $m_1$ is a fraction strictly between them. Then the mediant of $x$ and $m_1$ is a fraction strictly between $x$ and $m_1$, and so on. This gives an endless list $x < \dots < m_3 < m_2 < m_1 < y$ of different fractions between $x$ and $y$. So there are infinitely many. (Simpler but less elegant: $\tfrac{x + y}{2}$ also works.)
