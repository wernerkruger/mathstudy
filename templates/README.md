# Templates

- [problem-set.tex](problem-set.tex): LaTeX template for writing up solutions. Copy it into a `work/` folder inside the module (for example `01-refresher/1.2-real-analysis-I/work/week03.tex`).
- [module-summary.md](module-summary.md): one-page end-of-module summary, written from memory.
- For the capstone dissertation, start from Overleaf's standard thesis or `amsart` template.

Compiled PDFs and LaTeX build files are ignored by `.gitignore`, so only your `.tex` sources are committed.
