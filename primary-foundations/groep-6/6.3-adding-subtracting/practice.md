# 6.3 Adding and subtracting: practice

[← Unit overview](README.md) · [Answers](answers.md)

**For you:** work on squared paper so the digits line up. Use the method you use at school. Estimating first is like a safety net. It helps you spot if something went wrong. No clock, no rush.

**For parents:** Sets 1–4 use mental strategies and *kolomsgewijs*. Only start Set 5 when school has taught *cijferend*.

## Set 2 · Building: estimating (*schatten*)

Round to the nearest hundred (or thousand) and estimate. You don't need the exact answer. If you want to, you can work it out afterwards and see how close you were.

1. 487 + 235 ≈ ______ + ______ = ______
2. 312 + 489 ≈ ______
3. 698 + 205 ≈ ______
4. 832 − 417 ≈ ______
5. 2 950 + 1 980 ≈ ______
6. 5 012 − 1 989 ≈ ______
7. Which is the best estimate for 396 + 411? Circle it: **700 · 800 · 900**
8. *Verhaaltjessom:* New football boots cost €48 and a jacket costs €79. About how much do they cost together? ______

> **Talk about it:** In question 3, both numbers were close to a round number. Did that make it easier?

## Puzzle corner (optional)

Use the digits **1, 2, 3, 4, 5, 6**, each one once, to make two three-digit numbers.

```
   [ ][ ][ ]
 + [ ][ ][ ]
```

- Make a sum. Now make a bigger one.
- What's the **biggest** sum you can make?
- How **close to 1 000** can you get?
- *Big challenge:* now subtract instead. What's the **smallest** difference you can make?
