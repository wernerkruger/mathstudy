# 6.7 Measuring, time and money: practice

[← Unit overview](README.md) · [Answers](answers.md)

**For you:** you can use a ruler, a real clock, coins or a calendar for any of these. Measuring things for real is a great way to check. No clock timing you, though!

**Handy facts:**

```
1 km = 1 000 m      1 m = 100 cm      1 cm = 10 mm
1 kg = 1 000 g      1 l = 10 dl = 1 000 ml
1 hour = 60 minutes      1 minute = 60 seconds      1 day = 24 hours
```

## Set 3 · Building: perimeter (*omtrek*) and area (*oppervlakte*)

Each square is 1 cm by 1 cm.

```
Shape A                         Shape B
+--+--+--+--+--+                +--+--+--+--+
|  |  |  |  |  |                |  |  |  |  |
+--+--+--+--+--+                +--+--+--+--+
|  |  |  |  |  |                |  |  |  |  |
+--+--+--+--+--+                +--+--+--+--+
|  |  |  |  |  |                |  |  |  |  |
+--+--+--+--+--+                +--+--+--+--+
                                |  |  |  |  |
                                +--+--+--+--+
```

1. What is the perimeter of shape A? ______ cm
2. What is the area of shape A? ______ cm²
3. What is the perimeter of shape B? ______ cm
4. What is the area of shape B? ______ cm²
5. Which shape has the bigger area? ______
6. *Verhaaltjessom:* A vegetable garden is 6 m long and 2 m wide. How many metres of fence go all the way round it? ______
7. *Verhaaltjessom:* What is the area of the same garden? ______ m²
8. A rectangle has an area of 24 squares. One side is 6 squares long. How long is the other side? ______
9. What is the perimeter of a square with sides of 10 cm? ______

> **Talk about it:** Shapes A and B have the same perimeter. Do they have the same area? Does that surprise you?

## Puzzle corner (optional)

You have a piece of string **24 cm** long. You make it into a rectangle on squared paper (whole centimetres only).

- Make one rectangle. What is its area?
- Make a different one. Is the area the same?
- *Big challenge:* find all the possible rectangles. Which one has the **biggest** area? Which has the **smallest**? Can you see a pattern?
