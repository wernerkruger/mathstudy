# 6.1 Numbers to 100,000: practice

[← Unit overview](README.md) · [Answers](answers.md)

**For you:** do one set at a time. There's no clock. You can use a place-value table, a number line, or play money to help. If something feels tricky, skip it and come back later, or ask. At school big numbers are written like 45.302 or 45 302. Here we use a space.

**For parents:** start with Set 1 even if it looks too easy. Stop after one set. Sets 4 and 5 can wait until week 3.

## Set 3 · Building: the number line (*getallenlijn*)

1. Which number is exactly halfway between 0 and 10 000? ________
2. Which number is halfway between 20 000 and 30 000? ________
3. Which number is halfway between 3 400 and 3 500? ________
4. This number line goes from 6 000 to 7 000. Each small step is the same size.

```
6 000                                              7 000
  |----|----|----|----|----|----|----|----|----|----|
       A                   B              C
```

   a. How much is each small step worth? ________
   b. A = ________   B = ________   C = ________

5. Keep counting: 45 000, 46 000, 47 000, ________, ________
6. Count back in hundreds: 12 300, 12 200, ________, ________
7. Count in ten-thousands: 15 000, 25 000, ________, ________
8. Which round number is exactly halfway between 69 990 and 70 010? ________
9. Draw your own line from 0 to 100. Put 25, 50 and 90 on it.

> **Talk about it:** How did you work out the size of each step in question 4? Is there another way?

## Puzzle corner (optional)

Use the digits **1, 2, 3, 4 and 5**, each one once, to make five-digit numbers.

- Can you make a number that rounds to **30 000** (to the nearest 10 000)?
- Can you find another one? And another?
- *Big challenge:* how many can you find altogether? How do you know you've found them all?

There is no hurry. You can come back to this over several days.
