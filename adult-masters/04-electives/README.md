# Phase 4 — Electives

After finishing the Phase 3 core ([03-masters-core](../03-masters-core/)), pick **one** elective and give it about **16 weeks at ~6 hours/week (~96 hours)**. A Masters programme normally includes one or two specialist courses beyond the core; this phase plays that role and usually feeds directly into the [capstone](../05-capstone/).

## How to choose

1. **Follow the core module you enjoyed most.** Each elective builds on one or two core modules (see the table). Enjoyment predicts whether you'll still be working in week 12.
2. **Think about the capstone.** Your dissertation topic will most likely come from the elective. Skim [05-capstone/topic-ideas.md](../05-capstone/topic-ideas.md) before choosing.
3. **Check the prerequisites honestly.** If a prerequisite module felt shaky, re-do its qualifying-level problems before starting.
4. **Read the first chapter of the primary text** of your top two candidates (an evening each) before committing.

Only one elective is planned. If you want a second one later, treat it as an optional extension after the capstone.

## Common structure

Each elective folder has a single `README.md` with: overview, prerequisites, texts, video lectures, a 16-week schedule, a checklist of key theorems, and exit criteria. Unlike the core modules, electives don't come with written notes and problem sets: part of the Masters-level skill is building your own. Use the [templates](../templates/) folder for weekly notes, and log progress in [PROGRESS.md](../PROGRESS.md).

A suggested weekly rhythm for electives:

- ~3 h reading the primary text with pen and paper;
- ~2 h exercises from the text (aim for 3–5 per week; write up one fully in LaTeX);
- ~1 h video, a secondary text, or writing a one-page summary of the week.

Weeks 15–16 of every elective are reserved for review and for scoping the capstone.
